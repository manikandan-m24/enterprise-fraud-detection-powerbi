📌 Executive Summary
Financial institutions process high transaction volumes daily where static rule-based systems struggle against dynamic fraud techniques. This project delivers a centralized operational intelligence dashboard that models transactional velocity, geographic displacement, device risks, and authentication vulnerabilities across ATM, POS, Web Banking, and Mobile App channels.

🖥️ Dashboard Architecture

Built with a consistent Dark Navy (`#0F172A`) executive UI theme, unified container framing, and interactive navigation:

Executive Overview:High-level transactional volumes, baseline fraud incidence rates, and portfolio-wide exposure metrics.
Risk Deep Dive:Anomaly score distributions, device risk correlation scatter clustering, risk gauge benchmarks, and a granular high-risk transaction audit trail.
Customer & Behavioral Analytics:Correlation of failed login velocities against anomaly spikes, amount tier fraud proportions, and a multi-dimensional channel authentication risk matrix.
Geographic & Velocity Risk:Spatial displacement tracking (geo-distance vs anomaly scores), card-not-present (CNP) vs card-present vulnerability splits, and channel velocity matrices.

🛠️ Tech Stack & Key Skills
BI Platform:Microsoft Power BI Desktop
Analytical Modeling:DAX (Data Analysis Expressions) for dynamic risk scoring, velocity indices, and condition-based measures
UI/UX Design:Custom enterprise dark UI, unified container cards, synchronized page-level routing, and dynamic cross-filtering
Data Focus:Multichannel transaction fraud, device risk modeling, anomaly detection, authentication auditing
